# Política de segurança

## Versões suportadas

Enquanto o MenuHelp estiver na fase `0.1.x`, apenas a versão mais recente do
código e o release mais recente receberão correções de segurança.

## Como reportar uma vulnerabilidade

Não publique informações sensíveis em uma issue pública. Use **Security →
Report a vulnerability** no repositório do GitHub. O mantenedor deve habilitar
o recurso **Private vulnerability reporting** antes do primeiro lançamento.

Inclua, quando possível:

- versão do macOS e arquitetura do Mac;
- versão ou commit do MenuHelp;
- passos mínimos para reproduzir;
- impacto observado;
- prova de conceito sem dados pessoais reais.

O recebimento será confirmado assim que possível. Detalhes e correções devem
permanecer privados até que exista uma versão corrigida.

## Escopo sensível

Relatos envolvendo histórico do clipboard, permissões de Acessibilidade,
execução de `m1ddc`/`ddcctl`, escrita fora de Application Support ou inclusão
acidental de credenciais são considerados prioritários.
